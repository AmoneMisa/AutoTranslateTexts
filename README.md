[БЕТА-ВЕРСИЯ]Данный инструмент создан и разрабатывается для автоперевода строк в модах. Это не переводчик в своём роде, как Deepl или Google Translate. Это патчер, который заменяет существующими переводами эти же тексты на другом языке.
Т.е., если у вас есть хоть одно упоминание данного текста на выбранном языке, например, название книги, оно будет перенесено на этот язык. Если же текст ни в одном моде не встречается на нужном языке - он остаётся без изменений. Патчер не изменяет файлы игры или моды сами по себе, он создаёт свой отдельный файл со всеми изменениями, которые необходимо включить в Вашем менеджере модов.
На данный момент поддерживаются следующие объекты для перевода: Имена NPC, Книги и Записки, Локации, Предметы, Диалоги.
Целевой язык перевода выбирается в настройках. Определение языка основано на письменности (кириллица, китайский, японский, корейский, арабский, греческий). Языки на латинице (английский, французский, немецкий, итальянский, испанский, польский и т.д.) невозможно отличить друг от друга и все они определяются как «Latin».
Каждый модуль можно включать и выключать по отдельности, а также логировать его изменения в отдельный .log файл. Файл сохраняется в папку с Synthesis.

[BETA-VERSION]This tool is created and developed for the automatic translation of strings in mods. It is not a translator like Deepl or Google Translate. It is a patcher that replaces existing translations of the same texts in another language.

So, if you have at least one mention of a specific text in the selected language, such as a book title, it will be transferred to that language. If the text does not appear in the desired language in any mod, it is left unchanged. The patcher does not change the game files or the mods themselves; it creates its own separate file with all the changes that need to be included in your mod manager.
At the moment, the following objects are supported for translation: NPC Names, Books and Notes, Locations, Items, and Dialogue.
The target language is chosen in the settings. Language detection is script-based (Cyrillic, Chinese, Japanese, Korean, Arabic, Greek). Latin-script languages (English, French, German, Italian, Spanish, Polish, etc.) cannot be told apart from one another and are all reported as "Latin".
Each module can be enabled or disabled separately, and its changes can be logged to a separate .log file. The file is saved in the Synthesis folder.

Plans:
- Add auto-translation for individual modules from a specific file.
